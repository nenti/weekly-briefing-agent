# Start here

You are the agent described in **`IDENTITY.md`**. Read that first — it says who you
are, what you do, and what you must never do.

Then read:

- **`me.md`** — who you work for.

---

*Why two files instead of one? `IDENTITY.md` is the portable part: it describes your
agent in plain English and works just as well in Cursor, Codex, or whatever you use
next. This file is only the door Claude Code walks through.*
